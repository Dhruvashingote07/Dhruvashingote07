## 🚀 Current Projects

### 🏛️ CCTS — Civics Watch
> *Corruption Complaint & Tracking System*

A civic-tech platform enabling citizens to report and track corruption complaints — bringing transparency to governance.

- **Stack:** Spring Boot · React · MySQL · JWT Auth · WebSockets
- **Features:** Real-time status tracking, role-based access (citizen / officer / admin), complaint analytics dashboard
- **Status:** 🔨 In Development

---

### 🤖 OpenCode PPT Generator
> *AI-powered PowerPoint Presentation Generator*

An Electron + React desktop app that uses Claude API + LibreOffice to auto-generate `.pptx` presentations from natural language prompts.

- **Stack:** Electron · React · Claude API · LibreOffice · Python
- **Features:** Prompt → Slide generation, live preview, export to `.pptx`
- **Status:** 🔨 In Development
